# 🖼️ Test Images Dataset
==========================

โฟลเดอร์สำหรับจัดเก็บชุดภาพทดสอบ (Test Dataset) สำหรับประเมินประสิทธิภาพและทดสอบระบบในสภาวะต่าง ๆ:

### หมวดหมู่ภาพทดสอบที่แนะนำ:
1. **Normal Cases**: ภาพเอกสารวางบนพื้นหลังตัดกันชัดเจน แสงสว่างพอดี
2. **Hard Cases**:
   - เอกสารวางบนพื้นหลังสีใกล้เคียงกับกระดาษ (Low Contrast)
   - ภาพมีเงาตกกระทบหรือแสงสะท้อน (Glare / Shadows)
   - ภาพถ่ายจากมุมเอียงมาก (> 60 องศา)
   - กระดาษยับหรือมีรอยพับ
